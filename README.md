# Glowy Calculator

A glowing, responsive calculator built with Next.js and React.

## Features

- Standard and scientific calculator modes
- Algebra and geometry formula reference
- What-if Lab with variable slider and graph
- Calculation history saved in the browser
- Light and dark themes
- Adjustable text size and Focus mode
- Developer profile popover

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```
